# Politique de confidentialité

L'application mobile **Jeannot** est développée par [{{company}} {{legalForm}}]({{companyUrl}}), en tant que développeur indépendant. Cette politique de confidentialité explique quelles données nous collectons, comment nous les utilisons et avec qui elles peuvent être partagées.

---

## 1. Données collectées

L'application Jeannot collecte les données suivantes :

### Données personnelles

- **Adresse e-mail** – Utilisée pour créer et gérer les comptes utilisateurs et pour communiquer avec les utilisateurs.
- **Emplacement du jardin** – Indiqué par l'utilisateur pour personnaliser l'expérience dans l'application.

### Données techniques et d'utilisation

- **Identifiant de l'appareil**
- **UUID de l'utilisateur** (un identifiant interne non personnel)
- **Données d'utilisation de l'application** (interactions, usage des fonctions, événements dans l'application)

---

## 2. Finalités de la collecte

Les données sont collectées pour :

- Fournir, maintenir et améliorer l'application
- Personnaliser l'expérience de l'utilisateur
- Analyser l'utilisation de l'application et comprendre le comportement des utilisateurs
- Détecter, diagnostiquer et corriger les bugs ou les problèmes techniques

---

## 3. Partage des données

### Services tiers

#### 🔹 Amplitude

Amplitude est un service d'analyse produit utilisé pour suivre le comportement des utilisateurs dans l'application. Les données partagées avec Amplitude peuvent inclure :

- UUID de l'utilisateur
- Localisation (si disponible)
- Adresse IP
- Informations sur l'appareil et la plateforme

[Politique de confidentialité d'Amplitude](https://amplitude.com/privacy)

#### 🔹 Sentry

Sentry est un outil de suivi des erreurs utilisé pour signaler les plantages et les bugs. Les informations partagées avec Sentry peuvent inclure :

- UUID de l'utilisateur
- Informations sur l'appareil
- Journaux d'erreurs

[Politique de confidentialité de Sentry](https://sentry.io/privacy/)

#### 🔹 Fournisseurs de modèles de langage (par exemple OpenAI)

Si vous utilisez des fonctions comme un **chatbot** ou tout assistant conversationnel dans l'application, certaines saisies peuvent être transmises à des fournisseurs tiers de modèles de langage (par exemple **OpenAI**) afin de générer des réponses.

Les données suivantes **peuvent être traitées** :

- Le texte de vos messages ou de vos questions
- Des métadonnées techniques (par exemple horodatage, appareil ou plateforme)
- La géolocalisation ou les informations de contexte que vous fournissez pendant la conversation

Ces fournisseurs **peuvent conserver des données** pour surveiller les abus, améliorer leurs services ou respecter leurs obligations légales, conformément à leurs propres politiques de confidentialité.

> **Remarque :** nous prenons des mesures pour réduire au minimum les informations personnelles partagées dans ce cadre. Toutefois, **évitez de saisir des données personnelles sensibles** lorsque vous utilisez les fonctions d'IA.

[Politique de confidentialité d'OpenAI](https://openai.com/privacy)
